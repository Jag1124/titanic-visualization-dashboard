# Titanic Visualization Dashboard

## Overview
This project is part of Data Science with Python Internship Task 4.
Titanic dataset is used to create a mini visualization dashboard.

## Steps Performed
- Data loading using pandas
- Data cleaning
- Feature engineering
- Data visualization using matplotlib and seaborn
- Insights added for each plot

## Tools Used
Python  
Pandas  
NumPy  
Matplotlib  
Seaborn  
Jupyter Notebook

## How to Run
Open the notebook file in Jupyter or Google Colab and run all cells.
